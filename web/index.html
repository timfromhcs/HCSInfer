Image Studio

      
Text-to-image and image-to-image need a diffusion runtime. There is no proven, browser-runnable WebGPU diffusion pipeline here, so this demo does not offer one and shows no fake render.

      

        
Where it runs
In the native HCSInfer app (stable-diffusion.cpp, Vulkan or CPU). The local app keeps this feature.

        
Why not here
A browser demo must not present a stub as a result. A WebGPU diffusion path is tracked as future work (ADR-013).

        
Parity
Chat, Vision, Models, Performance and Settings run in the browser; Image Studio, Train and the shell-based Agent are "local only".

      Features that need the native app
      
      
      These run in the native HCSInfer application, not in a browser tab. They are listed here so the demo does not imply more than it does.
      
      
      
        
      Image Studio
      Diffusion (text-to-image / image-to-image) through stable-diffusion.cpp on Vulkan or CPU.
      
        
      Model Vault
      Streaming multi-gigabyte models from the external drive, beyond what a browser tab should hold.
      
        
      Train
      Short local LoRA runs and the evaluation gate.
      
        
      Agent
      A coding agent with shell and file tools, confined to approved folders. A browser shell is out of scope by design.
      
        
      Vulkan kernels
      HCS compute kernels measured against the upstream baseline.
