# Open datasets for agentic tool calling and coding (HCS Train, ADR-012)

Status: research note, 2026-11-17. **Nothing here was downloaded.** No training run exists yet.

What was verified and how: the licence tag and size category below were read from the Hugging Face Hub repo metadata
through the Hub tools in this session ("Hub tag"). Statements about which model generated the data come from the
dataset card text seen in this session where marked "card", otherwise from the associated paper as remembered and
are marked "UNVERIFIED - read the card/paper before use". A Hub licence tag is not legal advice and says nothing about
the terms of the model that generated synthetic text; both are checked per ADR-012 before a dataset is admitted.

Policy reminder (ADR-012): the HCS validator rejects any record whose `generator` or `source` names Claude /
Anthropic / Opus / Sonnet / Haiku / Fable, requires an allow-listed SPDX licence per record, and does not accept
share-alike or non-commercial licences by default. Data produced by closed hosted models other than Claude is not
forbidden by the validator but needs a manual terms-of-service review and is NOT admitted by default.

## Not yet researched (next wave)

Coding-agent trajectories produced by open-weight models (for example SWE-agent/OpenHands runs with Qwen3-Coder or
similar) with a documented open generator; terminal-use trajectories; tool-call datasets in the exact format of the
LFM3-Omni chat template. Each needs the same licence + generator check before it enters a manifest.

## Admission checklist (per dataset)

1. Licence tag on the Hub AND in the repository files/card agree; record both URLs.
2. Generator model(s) documented, open-weight or human; terms of any hosted generator reviewed; not Claude.
3. Size: only a filtered subset is ever pulled (target 5-20 K records for the 2B model on this machine, ADR-012).
4. Run `DatasetValidator` over the converted JSONL; a report with `rejected > 0` is triaged, never ignored.
5. Held-out and regression sets are carved out BEFORE training and never overlap the training records.
6. Attribution text added to `THIRD_PARTY_NOTICES.md` (data section) and to the adapter's model card.
