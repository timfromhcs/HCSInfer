            HCS Agent
            
      
            A coding agent that runs against the local OpenAI-compatible endpoint of this server. It has no controls here because nothing is wired to it yet.
            
      
            
        
            Base
            Prime Agent (MIT licence), vendored at a pinned commit as an HCS engine adapter. Its source is added to the repository as a submodule; it is not built or started by HCSInfer yet.
            
        
            Model
            LFM3-Omni-2B Q8_0 as the local model. It needs a llama.cpp revision that supports the lfm3 architecture; the pinned revision has not been checked against it.
            
        
            Safety
            Tool calls confined to approved folders, no network by default, every shell and file call logged and cancellable.
            
        
            Shipping
            A sidecar in the portable folder until the single-executable gate (M7) passes.
            
        
            Meanwhile
            Chat shows tool-call deltas as expandable blocks when the server sends them. It never executes them.
            
      
            
    
            
  
            

  
  
            
    
            
      
            Planned, not available in this build
            
      
            HCS Train
            
      
            Datasets, small LoRA runs and evaluation for local models. No training controls are shown because no training endpoint exists yet.
            
      
            
        
            Scope
            Short LoRA runs on a 2B model on this machine. Real tokens per second and wall time will be reported; a toy run is never presented as a quality result.
            
        
            Data
            Permissively licensed open datasets with the licence recorded per dataset, the project's own tests and traces, and human-approved examples. No distillation from proprietary model outputs.
            
        
            Evaluation
            A fixed held-out set for tool calling and coding, run before and after. An adapter is kept only if it improves that set without regressing the base model.
            
        
            Self-improvement
            Reflect on trajectories, propose a small prompt or dataset change, evaluate, keep only on measured gain, keep rollback snapshots.
